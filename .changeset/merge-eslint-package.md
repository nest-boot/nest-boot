Merge `@nest-boot/eslint-config` and `@nest-boot/eslint-plugin` into `@nest-boot/eslint` as a standard ESLint v9 plugin (`{ meta, rules, configs }`). Use `configs.recommended` for the full shared flat configuration, `configs.standard` for external JS/TS/JSDoc/Prettier presets only, or `configs.rules` for Nest Boot custom rules only.
