Store user, member and independent system-account API keys in one table using a polymorphic owner. Add administrator-session management of system accounts and their keys, explicit platform permissions, database owner integrity and cleanup triggers, and a data-preserving example migration. Expose database options to feature registration factories and allow GraphQL connections to query a separate persistent entity. Keep the release in the 8.x series.
