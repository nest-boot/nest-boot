# Security Policy

Do not disclose suspected vulnerabilities, credentials, customer data, or usable exploit details in a public Issue or pull request.

Use GitHub's [private vulnerability reporting](https://github.com/nest-boot/nest-boot/security/advisories/new). If that option is unavailable, contact a repository maintainer privately through their GitHub profile before sharing sensitive details.

Provide the minimum information needed to investigate:

- affected `@nest-boot/*` package and exact version;
- impact and prerequisites;
- sanitized reproduction or failing test;
- relevant environment and peer dependency versions;
- suggested mitigation, if known.

Test only against systems and data you are authorized to use. Revoke or rotate exposed credentials immediately, and do not attach production logs or customer content.
