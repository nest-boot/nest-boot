The `@nest-boot/i18n` module provides internationalization (i18n) support via [i18next](https://www.i18next.com/), with file-system-based translation loading and automatic HTTP language detection.

## Installation

```bash
npm install @nest-boot/i18n i18next i18next-fs-backend i18next-http-middleware
# or
pnpm add @nest-boot/i18n i18next i18next-fs-backend i18next-http-middleware
```

## Basic Usage

```typescript
import { Module } from "@nestjs/common";
import { I18nModule } from "@nest-boot/i18n";

@Module({
  imports: [
    I18nModule.register({
      fallbackLng: "en",
      supportedLngs: ["en", "zh"],
    }),
  ],
})
export class AppModule {}
```

## Using Translations

### Using the t() Helper

```typescript
import { Injectable } from "@nestjs/common";
import { t } from "@nest-boot/i18n";

@Injectable()
export class GreetingService {
  getWelcomeMessage(name: string): string {
    return t("welcome", { name });
  }
}
```

### Injecting the i18next Instance

```typescript
import { InjectI18n } from "@nest-boot/i18n";
import { Injectable } from "@nestjs/common";
import type { i18n } from "i18next";

@Injectable()
export class GreetingService {
  constructor(@InjectI18n() private readonly i18n: i18n) {}

  getGreeting(): string {
    return this.i18n.t("welcome", { name: "World" });
  }
}
```

`InjectI18n()` is a Nest dependency-injection decorator for constructor parameters or properties; it is not a controller route-parameter decorator. For request-specific language selection, use `t()`, which reads the i18next instance stored in an active `RequestContext` by the HTTP middleware. In jobs, CLI commands, or other code without an active context, use the injected instance or create a `RequestContext` first.

## Features

- **i18next Integration** - Full i18next API with NestJS DI
- **File-System Backend** - Automatic loading from JSON translation files
- **HTTP Language Detection** - Auto-detect language from request headers
- **Request-Scoped** - Per-request language via request context
- **Dependency Injection** - `@InjectI18n()` injects the configured i18next instance
- **Helper Function** - `t()` utility for quick translations
