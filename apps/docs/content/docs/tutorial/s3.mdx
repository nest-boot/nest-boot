---
title: "S3"
description: "Provide one global AWS S3 client with environment, synchronous, or asynchronous configuration."
---

The `@nest-boot/s3` module creates one AWS SDK `S3Client`, exposes it globally, and destroys it when the Nest application shuts down.

## Installation

```bash
pnpm add @nest-boot/s3 @aws-sdk/client-s3
```

## Environment Configuration

Import `S3Module` once to configure the client from environment variables:

```typescript
import { S3Module } from "@nest-boot/s3";
import { Module } from "@nestjs/common";

@Module({
  imports: [S3Module],
})
export class AppModule {}
```

| Variable               | Description                                                  |
| ---------------------- | ------------------------------------------------------------ |
| `S3_ENDPOINT_URL`      | Optional S3-compatible endpoint, such as a MinIO endpoint    |
| `S3_ACCESS_KEY_ID`     | Optional access key; use together with the secret access key |
| `S3_SECRET_ACCESS_KEY` | Optional secret access key; use together with the access key |
| `S3_REGION`            | Optional AWS region                                          |
| `S3_FORCE_PATH_STYLE`  | Set to `true` for path-style bucket URLs                     |

When credentials or a region are omitted, the AWS SDK uses its default provider chains. `S3_BUCKET` belongs to consumers such as `@nest-boot/file-upload`; it is not an `S3Client` option.

## Explicit Configuration

`register()` accepts the AWS SDK `S3ClientConfig`. Explicit options override values loaded from the environment:

```typescript
import { S3Module } from "@nest-boot/s3";

@Module({
  imports: [
    S3Module.register({
      endpoint: "http://localhost:9000",
      credentials: {
        accessKeyId: "minio",
        secretAccessKey: "password",
      },
      forcePathStyle: true,
      region: "us-east-1",
    }),
  ],
})
export class AppModule {}
```

## Asynchronous Configuration

Use `registerAsync()` when another provider supplies the configuration:

```typescript
import { S3Module } from "@nest-boot/s3";
import { ConfigService } from "@nestjs/config";

@Module({
  imports: [
    S3Module.registerAsync({
      inject: [ConfigService],
      useFactory: (config: ConfigService) => ({
        endpoint: config.get("S3_ENDPOINT_URL"),
        region: config.get("S3_REGION"),
      }),
    }),
  ],
})
export class AppModule {}
```

## Client Injection

Because the module is global, feature modules can inject `S3Client` without importing `S3Module` again:

```typescript
import { S3Client } from "@aws-sdk/client-s3";
import { Injectable } from "@nestjs/common";

@Injectable()
export class ObjectStorageService {
  constructor(private readonly s3Client: S3Client) {}
}
```
