---

The `@nest-boot/redis` module provides a simple Redis integration using [ioredis](https://github.com/redis/ioredis) with environment-based configuration.

## Installation

```bash
pnpm add @nest-boot/redis ioredis
```

## Module Registration

```typescript
import { RedisModule } from "@nest-boot/redis";
import { Module } from "@nestjs/common";

@Module({
  imports: [RedisModule],
})
export class AppModule {}
```

The global module reads `REDIS_URL` and parses it into ioredis connection options. Use `redis://` for a plain connection or `rediss://` to enable TLS, and percent-encode credentials containing URL-reserved characters. Use explicit module options when a URL is not suitable.

### Custom Configuration

```typescript
import { RedisModule } from "@nest-boot/redis";

@Module({
  imports: [
    RedisModule.register({
      host: "redis.internal",
      port: 6379,
      password: "secret",
    }),
  ],
})
export class CommonModule {}
```

## Usage

The module registers the `ioredis` `Redis` class as its provider token, so inject the client directly by type:

```typescript
import { Injectable } from "@nestjs/common";
import Redis from "ioredis";

@Injectable()
export class CacheService {
  constructor(private readonly redis: Redis) {}

  async get(key: string): Promise<string | null> {
    return this.redis.get(key);
  }

  async set(key: string, value: string, ttl?: number): Promise<void> {
    if (ttl) {
      await this.redis.set(key, value, "EX", ttl);
    } else {
      await this.redis.set(key, value);
    }
  }
}
```
