title: "验证器"
description: "NestJS 验证工具，集成 class-validator。"
---

`@nest-boot/validator` 提供基于 [class-validator](https://github.com/typestack/class-validator) 的国际化验证装饰器。它本身不会注册 Nest 模块，也不会自动启用全局验证管道。

## 安装

```bash
pnpm add @nest-boot/validator @nest-boot/i18n class-validator class-transformer
```

## 用法

在 `main.ts` 中全局应用 `ValidationPipe`：

```typescript
import { ValidationPipe } from "@nestjs/common";
import { NestFactory } from "@nestjs/core";
import { AppModule } from "./app/app.module";

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalPipes(
    new ValidationPipe({
      transform: true,
      forbidUnknownValues: false,
    }),
  );

  await app.listen(process.env.PORT ?? 4000);
}

void bootstrap();
```

### 验证输入类型

Nest Boot 装饰器可以和标准 `class-validator` 装饰器一起使用。默认错误消息通过 `@nest-boot/i18n` 的 `validation` 和 `property` 命名空间解析。

```typescript
import { Field, InputType } from "@nest-boot/graphql";
import { IsEmail, IsTimezone, Length } from "@nest-boot/validator";
import { IsString } from "class-validator";

@InputType()
export class CreateUserInput {
  @IsString()
  @Length(2, 80)
  @Field(() => String)
  name!: string;

  @IsEmail()
  @Field(() => String)
  email!: string;

  @IsTimezone()
  @Field(() => String)
  timezone!: string;
}
```

该包还导出了 `ArrayLength`、`IsDate`、`IsDomain`、`IsNumberString`、`IsUrl`、`Min`、`Max`，以及 `IsGreaterThan` 等数值比较装饰器。为方便使用，它还从 `class-validator` 重新导出了 `IsOptional` 和 `ValidateNested`。
