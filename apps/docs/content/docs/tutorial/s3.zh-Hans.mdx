---
title: "S3"
description: "通过环境变量、同步或异步配置提供全局 AWS S3 客户端。"
---

`@nest-boot/s3` 模块会创建一个 AWS SDK `S3Client`，将它注册为全局 provider，并在 Nest 应用关闭时销毁客户端。

## 安装

```bash
pnpm add @nest-boot/s3 @aws-sdk/client-s3
```

## 环境变量配置

在应用中导入一次 `S3Module`，即可通过环境变量配置客户端：

```typescript
import { S3Module } from "@nest-boot/s3";
import { Module } from "@nestjs/common";

@Module({
  imports: [S3Module],
})
export class AppModule {}
```

| 环境变量               | 说明                                               |
| ---------------------- | -------------------------------------------------- |
| `S3_ENDPOINT_URL`      | 可选的 S3 兼容 endpoint，例如 MinIO endpoint       |
| `S3_ACCESS_KEY_ID`     | 可选的 access key，需与 secret access key 一起使用 |
| `S3_SECRET_ACCESS_KEY` | 可选的 secret access key，需与 access key 一起使用 |
| `S3_REGION`            | 可选的 AWS region                                  |
| `S3_FORCE_PATH_STYLE`  | 设为 `true` 时使用 path-style bucket URL           |

未提供凭证或 region 时，AWS SDK 会使用默认 provider chain。`S3_BUCKET` 属于 `@nest-boot/storage`、`@nest-boot/file-upload` 等消费模块，并不是 `S3Client` 配置项。

## 显式配置

`register()` 接受 AWS SDK 的 `S3ClientConfig`。显式选项会覆盖从环境变量读取的值：

```typescript
import { S3Module } from "@nest-boot/s3";

@Module({
  imports: [
    S3Module.register({
      endpoint: "http://localhost:9000",
      credentials: {
        accessKeyId: "minio",
        secretAccessKey: "password",
      },
      forcePathStyle: true,
      region: "us-east-1",
    }),
  ],
})
export class AppModule {}
```

## 异步配置

需要从其他 provider 获取配置时，可使用 `registerAsync()`：

```typescript
import { S3Module } from "@nest-boot/s3";
import { ConfigService } from "@nestjs/config";

@Module({
  imports: [
    S3Module.registerAsync({
      inject: [ConfigService],
      useFactory: (config: ConfigService) => ({
        endpoint: config.get("S3_ENDPOINT_URL"),
        region: config.get("S3_REGION"),
      }),
    }),
  ],
})
export class AppModule {}
```

## 注入客户端

因为该模块是全局模块，功能模块无需再次导入 `S3Module`，即可注入 `S3Client`：

```typescript
import { S3Client } from "@aws-sdk/client-s3";
import { Injectable } from "@nestjs/common";

@Injectable()
export class ObjectStorageService {
  constructor(private readonly s3Client: S3Client) {}
}
```
