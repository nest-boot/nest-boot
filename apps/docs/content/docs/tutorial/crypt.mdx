---
title: "Crypt"
description: "Symmetric encryption and decryption for sensitive data."
---

The `@nest-boot/crypt` module encrypts strings as compact JWE values using HKDF-SHA256 key derivation, A256GCMKW key management, and A256GCM content encryption. It is suitable for API keys, tokens, and other sensitive values at rest.

## Installation

```bash
pnpm add @nest-boot/crypt
```

## Module Registration

Set `CRYPT_SECRET` or `APP_SECRET` and import `CryptModule`, or register it explicitly:

```typescript
import { CryptModule } from "@nest-boot/crypt";
import { ConfigService } from "@nestjs/config";

const CryptDynamicModule = CryptModule.registerAsync({
  inject: [ConfigService],
  useFactory: (configService: ConfigService) => ({
    secret: configService.getOrThrow("CRYPT_SECRET"),
  }),
});
```

The resolved secret must be at least 32 characters and have at least 120 bits of estimated entropy. Generate one with:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

## Usage

```typescript
import { CryptService } from "@nest-boot/crypt";
import { Injectable } from "@nestjs/common";

@Injectable()
export class SecretService {
  constructor(private readonly cryptService: CryptService) {}

  async encrypt(value: string): Promise<string> {
    return await this.cryptService.encrypt(value);
  }

  async decrypt(encrypted: string): Promise<string> {
    return await this.cryptService.decrypt(encrypted);
  }
}
```

Both operations are asynchronous. `encrypt()` returns a five-part compact JWE string, and `decrypt()` accepts that serialized value.

## MikroORM Integration

Use the `@EncryptedProperty()` decorator from `@nest-boot/mikro-orm-crypt` for automatic field encryption. See the [MikroORM tutorial](/docs/tutorial/mikro-orm#encrypted-properties) for details.
