# Temporary Directory Module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish `@nest-boot/temporary-directory` 7.0.0 with static and dynamic NestJS registration and automatically cleaned request-context-scoped temporary directories.

**Architecture:** A configurable global NestJS module registers one named `RequestContext` middleware. The middleware resolves its trusted developer-configured base path, creates a `nest-boot-${randomUUID()}` request root, stores it in the context, and recursively removes it in `finally`; the injectable service creates unique child directories under that root.

**Tech Stack:** TypeScript 5.9, Node.js 24 filesystem/path/os/crypto APIs, NestJS 11 `ConfigurableModuleBuilder`, `@nest-boot/request-context`, Jest 29 with ts-jest, pnpm/Nx.

## Global Constraints

- Package name is `@nest-boot/temporary-directory` and initial version is exactly `7.0.0`.
- Static `TemporaryDirectoryModule` import uses `tmpdir()` without requiring an options provider.
- `register()` and `registerAsync()` accept `TemporaryDirectoryModuleOptions` with optional `basePath?: string`.
- Omitted or empty `basePath` uses `tmpdir()`; absolute paths are used directly; relative paths resolve from `process.cwd()`.
- `basePath` is trusted developer configuration and requires no traversal sandbox.
- Request roots are named exactly `nest-boot-${randomUUID()}` and only module-owned roots are removed.
- The configured base directory is never removed.
- Existing untracked `examples/` content must not be modified, staged, or committed.

- [ ] **Step 3: Implement request-root lifecycle**

Add the internal token:

```ts
/** Current request's module-owned temporary root. @internal */
export const TEMPORARY_DIRECTORY_ROOT = Symbol("TEMPORARY_DIRECTORY_ROOT");
```

In the module constructor, after `super()`, register one named middleware using the optional configured options:

```ts
const basePath = resolveBasePath(this.options?.basePath);

RequestContext.registerMiddleware(
  "temporary-directory",
  async (context, next) => {
    await mkdir(basePath, { recursive: true });
    const root = join(basePath, `nest-boot-${randomUUID()}`);
    await mkdir(root);
    context.set(TEMPORARY_DIRECTORY_ROOT, root);

    try {
      return await next();
    } finally {
      await rm(root, { force: true, recursive: true });
    }
  },
);
```

Do not remove `basePath`. Keep the module global, its options injection optional, and sync/async registrations unchanged.

- [ ] **Step 3: Implement the minimal service**

```ts
async create(): Promise<string> {
  if (!RequestContext.isActive()) {
    throw new Error("Temporary directory requires an active RequestContext");
  }

  const root = RequestContext.get<string>(TEMPORARY_DIRECTORY_ROOT);
  if (!root) {
    throw new Error("Temporary directory context is not initialized");
  }

  return await mkdtemp(join(root, "directory-"));
}
```
